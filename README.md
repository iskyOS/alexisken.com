# Personal Website

This is my personal website, served from this repo via GitHub Pages at [alexisken.com](https://alexisken.com).

Blown up and rebuilt September 2019. Refreshed September 2026.

## Stack

Plain HTML and CSS, no framework and no JavaScript. The only external dependency is the
[Inter](https://fonts.google.com/specimen/Inter) font from Google Fonts, with a system font fallback.

The stylesheet supports light and dark mode via `prefers-color-scheme`.

## Layout

- `index.html` — the whole site
- `assets/css/styles.css` — styles
- `assets/resume/` — current resume
- `assets/images/` — favicon and logo marks
